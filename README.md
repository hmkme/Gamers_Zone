# Gamers_Zone

A responsive neon-blue and purple gaming community website focused on PUBG Mobile.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.

## Included in this starter
- Responsive landing page and navigation
- Featured games section
- Community feed with demo post creation and likes
- Local demo gamer profile (browser localStorage)
- Sample leaderboard
- Tournament interest buttons

## Important
This is a front-end starter/demo. Profiles, posts, likes, and tournament interest are not shared with other users and are not stored on a server. Real accounts, shared community posts, moderation, and tournament registration need a backend and database.

## Publish with GitHub Pages
1. Create a public GitHub repository named `Gamers_Zone`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the public website URL after deployment.
